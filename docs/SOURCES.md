# Listing-source strategy

House Hunter starts near-free and treats acquisition separately from ranking.

## Tier 1 — authorized/structured
Use permitted APIs and feeds when available. These provide the highest-confidence facts.

## Tier 2 — public discovery
Search-engine indexed public pages may identify candidate addresses, URLs and snippets. House Hunter records the exact source and discovery time. A snippet is evidence, not a complete listing.

## Tier 3 — enrichment
Only promising candidates receive deeper research: source page where permitted, broadband, drive time, STR rules, hazards and photo analysis.

## Rules
- Never convert Unknown to No.
- Never bypass logins, access controls, robots or anti-bot systems.
- Deduplicate by normalized address first; coordinates/listing IDs can strengthen matching later.
- Preserve every source sighting for auditability and stale-data detection.
- Prefer cross-source confirmation when facts conflict.
- Listing status must be refreshed before presenting a property as currently available.
