# Source-backed research, September 28, 2026

This first detailed review covers the ten homes shown at the start of the review, not the whole 49-home collection. `data/research-2026-09-28.json` holds 73 criterion observations with public source URLs and the retrieval time. It is a hand-reviewed batch, not a recurring discovery service. Short factual paraphrases are used; listing descriptions and photos are not copied.

The existing import endpoint now accepts optional `research` with criteria and notes. Research stays in the existing Listing.facts JSON, so no database migration, credentials, deployment configuration, or Jev service changes are required. It survives a later basic discovery import. Criteria merge by key and review date; a newer unknown can withdraw an earlier score. Manual reviewed evidence is authoritative over automated evidence. All selected profile weights remain controlling, including zero.

This batch uses 100 for an explicitly supported fit, 0 for an explicit mismatch, and 65 for a partial indication requiring verification. Unknown and conflicting facts have a null score, including advertised room counts contradicted by the description. Source-stated means stated in the listing, not independently inspected or guaranteed. Healthcare access remains unknown throughout. Paved roads do not prove winter access; rental history does not prove legal eligibility; internet options do not establish speed. The review records these limits.

The displayed match remains the weighted average of known criterion scores. Ordering uses `50 + (match - 50) * coverage / 100`: unknown weight receives a neutral midpoint for ordering only, not a failure in the displayed match. This avoids a thin 100% early match automatically outranking a much better supported home. Coverage is weighted; the visible detail count is unweighted, and explicitly splits source statements from partial clues.
